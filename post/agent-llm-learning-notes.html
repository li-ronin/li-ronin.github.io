Agent 与大模型：从原理到实现

2026-10-20

把零散的问题连成一条学习路线：先理解系统为什么这样设计，再走通一个具体例子，最后用代码与实验检验理解。

每个主题都是独立文章，包含原理、实现示例、失败场景与练习。可以按顺序阅读，也可以从正在遇到的问题进入。

怎样阅读

工程主线：运行时 → 上下文与记忆 → 工具 → 编排 → 开发工作流 → 评测与可靠性。模型主线：注意力与推理 → 训练与对齐 → RAG。并发一篇为两条主线提供系统基础。

先不用背结论。读完一节后，尝试画出数据流、手算示例或修改示例参数，再对照练习中的验证条件。涉及个人项目的问题，需要自己的日志与实验作答，文章不会替代真实证据。

  1. 01 · Agent 运行时：把模型决策变成可靠的执行系统

    用修复 C++ 边界错误的完整链路，拆解模型、运行时、工具、状态与验证之间的责任。

  2. 02 · 上下文、压缩与记忆：让 Agent 在长任务中保持正确状态

    从一份 32K 预算算例出发，区分聊天记录、模型输入、任务状态与长期记忆，再设计可回退、可验证的压缩流程。

  3. 03 · 工具、Skill 与 MCP：能力怎样接入，流程怎样复用

    沿着一次读代码、修复、测试的轨迹，理解工具契约、技能发现、协议连接和权限检查各自解决的问题。

  4. 04 · 规划与多 Agent：把复杂任务拆成可检查的依赖关系

    从单 Agent 的观察循环走向计划图、并行分工与结果合并，理解多 Agent 何时真正有用。

  5. 05 · 从一个注意力矩阵到逐词生成：理解 LLM 的计算过程

    手算一次注意力，写出张量形状，再沿着位置编码、KV Cache、GQA 与推测解码追踪一次生成。

  6. 06 · 从示范到偏好再到奖励：把 SFT、DPO、GRPO 放回训练过程

    用同一个小任务对照训练数据、损失和反馈，并计算一次 SFT、DPO 与组内优势；进一步理解 LoRA、量化与评测。

  7. 07 · 把文档变成可靠证据：从解析、检索到引用与版本回滚

    以一组带版本和访问权限的自造服务文档，逐步走完入库、切块、混合检索、重排、生成、冲突处理和错误回滚。

  8. 08 · AI Coding：从可验证的规格到云电脑执行闭环

    用一个性能日志统计工具贯穿规格、实现、验证和交付，再拆解 Computer Use 的观察、坐标、权限与结果验证。

  9. 09 · Agent怎样算可靠：评测、证据、成本与失败恢复

    从一次假想任务评测出发，拆分结果、过程和风险指标，推导成本口径，设计幂等恢复，并把项目判断落实为可复核证据。

  10. 10 · 线程池与背压：从吞吐推导到有界队列实现

    区分线程数、排队和下游容量，用负载数字推导稳定条件，再实现一个有界C++队列，理解流式处理为什么仍然可能耗尽内存。
